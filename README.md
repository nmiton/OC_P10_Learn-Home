# Learn@Home

## Contexte

Je suis employé depuis 5 ans chez **Dev4U**, où je suis actuellement **Lead Développeur** pour l'entité web. Dev4U est une entreprise de services du numérique spécialisée dans le développement d’applications mobiles et de solutions web.

Notre client, **Learn@Home**, est une plateforme qui met en relation des enfants en difficulté scolaire avec des bénévoles, pour des sessions d'aide en ligne. Le projet a pour but de faciliter ces interactions en ligne, de manière sécurisée et efficace.

## Mission

En tant que Lead Développeur, ma mission pour ce projet inclut les tâches suivantes :

- Définir les besoins client pour préparer la réunion de lancement
- Documents : Use Cases, User Stories, Maquettes, Kanban
