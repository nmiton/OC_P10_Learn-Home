# Learn@Home

## Contexte

Je suis employé depuis 5 ans chez **Dev4U**, où je suis actuellement **Lead Développeur** pour l'entité web. Dev4U est une entreprise de services du numérique spécialisée dans le développement d’applications mobiles et de solutions web.

Notre client, **Learn@Home**, est une plateforme qui met en relation des enfants en difficulté scolaire avec des bénévoles, pour des sessions d'aide en ligne. Le projet a pour but de faciliter ces interactions en ligne, de manière sécurisée et efficace.

## Mission

En tant que Lead Développeur, ma mission pour ce projet inclut les tâches suivantes :

- **Définir les besoins du client** : Collaborer avec les parties prenantes pour identifier et clarifier les besoins spécifiques du projet.
- **Préparation de la réunion de lancement** : Organiser et structurer les informations pour un démarrage efficace du projet.
- **Documentation** :
  - **Cas d’usage** : Décrire les scénarios d’utilisation pour comprendre comment les utilisateurs interagiront avec la plateforme.
  - **User stories** : Rédiger les user stories pour capturer les exigences fonctionnelles du projet.
  - **Maquettes** : Créer des maquettes pour visualiser l'interface utilisateur et les flux de travail.
  - **Kanban** : Mettre en place un tableau Kanban pour gérer et suivre l'avancement du projet.

## Objectifs du Projet

- **Améliorer l'accessibilité et l'efficacité** de la plateforme Learn@Home pour les enfants en difficulté scolaire.
- **Faciliter la communication** entre les enfants et les bénévoles via une interface conviviale.
- **Assurer une mise en œuvre réussie** grâce à une documentation complète et une gestion de projet rigoureuse.
